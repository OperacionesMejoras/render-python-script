# Dental Scan Reporter Python

Repositorio de scripts en Python para la generación y reporte de renderizados/análisis de escaneos dentales.

## Requisitos

- Python 3.9+
- Dependencias indicadas en `requirements.txt`

## Instalación

```bash
python -m venv .venv
# En Windows:
.venv\Scripts\activate
# En Linux/macOS:
source .venv/bin/activate

pip install -r requirements.txt
```

## Uso

Consulte `example_run.py` o `dental_scan_reporter.py` para ver la implementación y ejecución del reporte.
